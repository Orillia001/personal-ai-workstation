# Workstation-Visual-Console

## 目标

为 Personal AI Workstation 建立统一的本地可视化控制台，并提供 Codex 插件入口。

首版不重写工作站后端：继续复用 `ws.ps1`、`Tools/workstation.py`、SQLite 状态库和现有 `/api/*` 接口。浏览器前端负责状态、项目、任务、运行、审批和知识检索的可视化；Codex 插件负责自然语言入口、操作说明和后续 MCP 工具封装。

## 首版交付物

- 信息架构与技术选型记录
- 可独立预览的前端原型
- 对接现有本地 API 的适配层
- 响应式浏览器工作台：动态项目与软件入口、文件扫描计划和确认复制、PowerShell Codex CLI、Codex 只读规划、执行申请/审批/执行，以及状态/模型/适配器/课程 API
- 原生 Windows x64 exe 留作备选构建产物，不作为默认入口
- Codex 插件骨架与最小工具清单
- 启动、验证和回退说明

## 安全边界

- 服务仅监听 `127.0.0.1`
- 读操作可直接执行；写操作沿用工作站审批机制
- 网页内交互式终端可接收并执行用户手动输入的任意 PowerShell 命令；终端会话由用户显式启动，并以所选项目为初始目录
- 其他浏览器操作继续调用工作站具名 API；Codex 自动写入操作仍走审批流程，不能自动向交互式终端提交命令
- 文件接入先扫描并显示哈希计划；只有用户在网页再次确认后才调用复制 API，保留来源并跳过目标冲突
- Codex CLI 通过固定项目名接口在独立 PowerShell 窗口启动；不得接受任意路径或命令文本
- 首页项目读取使用轻量健康/概览接口，不等待模型、课程或软件扫描；连接问题由内置自检说明
- 不读取或展示密钥值，不绕过项目权限和人工确认

## 工作约定

- 原始资料放在 `01_sources`，不覆盖。
- 数据、代码、图表、正文和输出分别归档。
- 每次阶段变化更新 `12-status.md`。
- 高风险操作遵循工作站根目录 `AGENTS.md`。

## 正式网页版工作台

打开本机 `http://127.0.0.1:8765/workbench`。原布局 Demo 已作为正式骨架，站点首页 `/` 和日常启动器也打开该界面；旧版工具页保留在 `/workbench/legacy`，原 Demo 地址 `/workbench/layout-prototype` 是兼容别名。左侧按功能分类选择项目和小项目；中央是 VS Code 风格的分割内容区。顶部“＋”选择整块、左右、上下、三栏、主区加右侧上下或四格。拖动分割线可直接调整相邻区域的比例，也可聚焦分割线后用方向键微调。内容区紧贴分割线，没有额外缝隙。切换布局时复用已有内容，不足的区域补空白内容区；超出当前布局数量的内容继续保存，再切回较多区域的布局会重新显示。

项目栏右侧边界也可拖动以调整栏宽，聚焦边界后可用左右方向键微调。点击项目栏顶部的收起按钮或最左侧活动栏的项目图标可隐藏、恢复项目栏；窄屏时通过中央顶部的项目图标操作。栏宽会自动保存。

每个内容区只容纳一种主内容。空白区的“＋”可选文档、待办、内置浏览器、项目文件资源管理器、页面内 pwsh 终端或自定义；常用的浏览器、文件、终端、自定义也可从“＋”旁边直接打开。笔记与外部链接通过主内容旁的“＋ 标注”插入，选中文字时保存引用片段，点击引用可回到正文；没有选区时关联整份内容。

选定主内容后，点内容区顶部“取消”可回到该区域原来的空白自由选择界面，并清除该区域的内容与标注；分割布局及其他内容区不受影响。若该区域正在运行终端，会先关闭终端会话。

内置浏览器是铺满内容区的可交互网页空间：从新标签页输入 http(s) 网址或域名，在网页内直接点击、输入和跳转；窄工具栏可回到新标签页、重新打开地址，并在手动输入过的网址之间前进/返回。切换侧栏或调整分割线时保留已打开网页的现场，标注可按需展开。部分网站会拒绝 iframe 嵌入，或因浏览器隔离限制无法登录；此时使用工具栏的“在新标签页打开”。工具栏无法读取跨站网页内部跳转后的真实网址，其前进/返回只记录手动输入的网址。文件资源管理器浏览当前项目目录并预览常见文本文件，不修改项目文件。终端由用户点击启动，在所选项目目录运行持久 pwsh 会话；用户可在网页手动提交任意 PowerShell 命令，输出显示在当前内容区。自定义可用一句话描述所需内容，并选择格式、UI、UX；提交后只读 Codex 生成受限字段预览，不自动写入项目。

项目选择、侧栏宽度、分割布局和比例、文档、待办、自定义字段及已保存标注会自动写入本机 `State/workstation.db`，刷新或重开工作站后恢复。底部状态栏显示保存状态；若其他标签页先保存，当前页会提示载入最新版本。终端会话、命令和输出、Codex 描述草稿、网页内部状态不保存；浏览器仅恢复去除账号信息、查询串和片段后的地址，文件目录会重新读取。

项目栏标题右侧“＋”可新增功能分类；分类行右侧“＋”会创建真正的新项目，调用工作站既有项目创建接口，在 `Projects` 下建立标准目录和控制文件。分类行的“↳”单独用于把已有项目归入分类，不移动目录。项目行右侧“＋”可新增小项目。新项目与小项目都可选择推荐的初始布局，之后仍可修改；各小项目有独立的内容区、标注、布局和手动进度。项目显示名可用中文，目录名须符合工作站命名规则；目录名留空时自动生成。分类归属和页面状态会自动保存；文件、终端和只读 Codex 使用真实父项目目录。

活动栏“⌂”和项目栏顶部“中控台”打开全局总览 Demo。中央显示当前分类、项目、小项目数量、各项目累计使用时长及手动进度中的小项目；点击项目可打开对应工作台，“继续工作”回到当前选中的工作台。使用时长只在项目工作台位于前台时累计，切换到中控台或其他窗口后暂停，定期随界面状态保存。中控台与项目工作台之间切换时保留各小项目内容，当前页面类型随界面状态保存。右侧聊天技术路线已暂停，入口和请求接口不再提供；工作流栏目已移除。

## 正式教育思维导图（2026-10-20）

打开本机工作台，选择「教育学习 → 知识网络」或 University 下任意课程。教育区域使用已确认的深色A版：同一画布上按“课程 → 章节模块 → 细分知识点”呈现，顶部只有搜索和当前位置文字。章节展开/收起时保持点击位置；点知识点阅读正文、教材页码、其他知识关系及掌握证据。

画布支持鼠标、单指或笔拖动、双指平移与捏合；松开一指后可续拖，触控板横纵滚动平移、捏合缩放。右下角缩小/全图/放大，键盘方向键移动、正负号缩放、0全图。各科的展开、选择与视角分别保存于当前浏览器，刷新或课程往返可恢复。原力导向的自动散点和关系筛选已由分层导图替代，其他关系仍在详情中查看。

直达：http://127.0.0.1:8765/workbench?education=machine-design 。详情底部“进入课程工作区”可进入原分割内容；原入口可返回思维导图。全局项目栏继续遵循用户当前设置，教育样式仅作用于教育视图。

### Obsidian双向学习状态

知识点详情中“在 Obsidian 中打开”直接调用本机已绑定笔记；支持触控和键盘。学习状态通过原有正式API保存，带修订号避免覆盖另一处刚完成的编辑；成功前不改变节点状态。未绑定或读取失败时禁用标记，失败可重试。

在Obsidian中修改笔记顶部“学习状态”为“未开始”“学习中”“已学习”“待复习”，工作站前台每5秒及返回窗口时读取更新。已学习节点出现绿色圆点和勾选，待复习为橙色。掌握证据独立显示，学习完成不会产生已验证掌握结论；更新状态保留笔记正文。
