# 工作站课程提醒 Edge 扩展

此目录是工作站的本地 Edge Manifest V3 扩展，不使用 Playwright、npm 依赖或云服务。它只匹配雨课堂 `*.yuketang.cn`、课程伴侣 `http://eol.imut.edu.cn/meol/personal/*` 和本机 `http://127.0.0.1:8765`。

## 读取范围

工作台打开时，扩展检查当前 Edge 中已打开的雨课堂页面；没有可用页面时，会在后台新建雨课堂首页标签。课程页加载完成后，读取器仅从页面可见文字提取顶部“最近一周有 X 门考试”中的数字。找不到蓝条时，只有确认课程页已加载才记录 0；登录页或加载失败不会记为 0。Cookie、密码、完整登录链接和页面正文不会进入扩展消息或工作站数据库。这是最近一周考试数量，不等于所有未完成作业。

结果由扩展送到工作台页面，再由工作台已有的令牌保护 API 校验并写入本机 SQLite。读取成功会替换上次快照；需要登录或读取失败时会记录状态并保留上次成功快照。新建雨课堂标签后若页面加载失败，也会回传错误状态，不再一直显示“扩展无响应”。工作台卡片提供手动重试；登录失效时先在 Edge 中完成登录，再点“立即同步”。

课程伴侣使用用户已登记的个人页地址。扩展优先读取 Edge 中已打开的个人页；未打开时，在后台打开公开地址。读取器只看“任务提醒”里的作业数字与“待提交作业”列表，返回标题、课程和截止时间；不执行页面 `onclick`，不读取其他学习记录。作业数量为 0 时，页面节点须稳定出现 1.5 秒；节点缺失或数量与可见列表冲突时返回错误，不把它误记为 0。

## 本机加载

1. 在工作站根目录运行 `node .\Projects\Workstation-Visual-Console\04_code\rain-edge-extension\build-reader.cjs`，生成扩展所需的 `rain-reader.js` 和 `theol-reader.js`。本次已生成。
2. 在 Edge 打开 `edge://extensions`，由用户手动开启“开发人员模式”，选择“加载解压缩的扩展”，然后选本目录。
3. 确认扩展显示为“工作站 · 课程提醒”，并允许新增的课程伴侣网站权限，再打开 `http://127.0.0.1:8765/workbench`。扩展启用和更新都由用户在 Edge 扩展页操作。

更新本目录源码后，在 `edge://extensions` 点击该扩展卡片上的“重新加载”，再刷新 **Edge 中**的工作台标签；Codex 内置浏览器无法运行 Edge 扩展。

关闭或移除扩展也在 `edge://extensions` 完成。首次加载是一次本机软件安装/浏览器配置操作，Codex 不会替用户点击或修改 Edge 设置。

## 本机检查

- `manifest.json` 使用 Manifest V3；脚本只处理雨课堂 HTTPS、课程伴侣指定 HTTP 个人页和本机工作台来源。
- `background.js` 仅在工作台加载或用户点“立即同步”时请求读取；一次只运行一个检查，自动重复触发有 60 秒间隔。
- `rain-content.js` 在雨课堂页面的隔离世界运行读取器；自动路径只读取页面可见文字，不发起站点 API 请求。
- `theol-content.js` 只读课程伴侣个人页；扩展后台只转递作业字段白名单。
- `workbench-content.js` 不读取令牌，只在两个课程站点与工作台之间转递白名单结果。
- 未安装扩展时，仍可在工作台复制 Snippet 并手动导入读取结果。
