# Domain docs

采用单一领域文档布局：station_root 下的 `GLOSSARY.md` 与 `docs/adr/`。各项目现有的课程规则、项目事实与来源索引继续作为事实来源。

## 读取

探索代码前，读取已存在的根目录 GLOSSARY.md，以及 docs/adr/ 中与当前改动有关的决策。术语、任务标题、接口与测试描述使用词表中已经明确的名称。发现与既有 ADR 冲突时指出具体决策和原因。

文件尚不存在时继续当前任务；当 domain-modeling 或 grill-with-docs 实际解决了术语或长期决策时再创建相应文件。词表存放含义，ADR记录具体选择与理由，项目状态和动态进度留在各自事实文件中。
