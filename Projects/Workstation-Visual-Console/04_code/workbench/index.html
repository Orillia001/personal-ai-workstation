Quick start

快速开始

这些命令只展示给你复制；本页面不会在后台执行 PowerShell。

查看工作站状态.\ws.ps1 state
自检网页服务和项目读取.\ws.ps1 workbench-diagnose
列出项目.\ws.ps1 projects
检查本地工具.\ws.ps1 tools
启动动态控制台.\ws.ps1 control
判断任务路线.\ws.ps1 route '描述你的任务'
打开 PowerShell Codex CLI.\Tools\open-codex-session.ps1 -ProjectName "Workstation-Visual-Console"

在 PowerShell 中先切换到 C:\Users\Orillia\workstation。文件扫描只生成计划；复制材料、执行审批动作或对外发布仍需按工作站规则确认。
