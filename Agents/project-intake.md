# 项目自动接入流程

触发示例：“接入挑战杯项目”“把这些资料整理成一个科研项目”“继续我的论文项目”。

## 自动执行

1. 识别或创建项目目录。
2. 建立标准目录和控制文件。
3. 获取用户明确给出的材料位置；若材料已在 `00_inbox`，直接清点。
4. 生成文件清单，计算 SHA-256，识别格式和重复项。
5. 检查本机可用工具并选择最小工具组合。
6. 保留 inbox 原文件，将副本无覆盖地归类，写入 `08_evidence/intake-manifest.csv`。
7. 提取可读文本、建立项目概览和下一步计划。
8. 更新 `10-README.MD` 与 `12-status.md`。
9. 用 Git diff 和任务输出验证结果。

## 必须停下确认

- 删除或覆盖文件。
- 修改已有原始材料。
- 移动原文件而不是复制资料。
- 安装软件、登录外部账号、调用收费 API。
- 上传、发送、提交、发布或推送。
