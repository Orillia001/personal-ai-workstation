问题：工作站知识网图线条交错、内容混杂时，什么阅读结构更清楚？在现有 `/workbench` 页面骨架内比较三种布局，尚未选择或接入正式版本。

- A 分层导图：默认推荐。左侧选模块，仅画当前模块的包含树；点知识点看正文与其他关系，可展开/收起、平移和缩放。
- B 大纲目录：按大纲阅读，模块与子节点可展开，详情按需打开。
- C 分栏浏览：模块、知识点、内容分成三栏，逐列定位。
